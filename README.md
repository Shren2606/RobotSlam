# RobotSlam

A ROS 2 SLAM and Navigation project for mobile robots, developed using **Ubuntu 24.04 and ROS 2 Jazzy**.

## 1. System Requirements

| Component | Version |
|---|---|
| Operating System | Ubuntu 24.04 LTS |
| ROS 2 | Jazzy Jalisco |
| Build System | Colcon |
| Dependency Manager | Rosdep |
| Programming Languages | C++ / Python |

## 2. Install ROS 2 Dependencies

Update Ubuntu packages:

```bash
sudo apt update
```

Install rosdep:

```bash
sudo apt install python3-rosdep
```

Initialize rosdep (first-time installation only):

```bash
sudo rosdep init
rosdep update
```

Optional: Install Gedit text editor:

```bash
sudo apt install gedit
```

## 3. Setup ROS 2 Environment

Load ROS 2 Jazzy:

```bash
source /opt/ros/jazzy/setup.bash
```

## 4. Clone Repository

```bash
cd ~
git clone -b dev https://github.com/Shren2606/RobotSlam.git
```

Enter the workspace:

```bash
cd ~/RobotSlam
```

## 5. Install Project Dependencies

Automatically detect and install dependencies declared in package.xml:

```bash
rosdep update

rosdep install \
  --from-paths src \
  --ignore-src \
  --rosdistro jazzy \
  -r -y
```

## 6. Build Workspace

Build all ROS 2 packages:

```bash
cd ~/RobotSlam
colcon build
```

Load the workspace environment:

```bash
source ~/RobotSlam/install/setup.bash
```

## 7. Configure Environment Automatically

To avoid running source commands every time a new terminal is opened, add them to `~/.bashrc`:

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc

echo "source ~/RobotSlam/install/setup.bash" >> ~/.bashrc
```

Apply changes:

```bash
source ~/.bashrc
```

## 8. Run ROS 2 Launch Files

General syntax:

```bash
ros2 launch <package_name> <launch_file>
```

Find available launch files:

```bash
find ~/RobotSlam/src -name "*.launch.py"
```

Example:

```bash
ros2 launch bumperbot_bringup bringup.launch.py
```

Replace the package name and launch filename with the actual launch file available in the repository.

## 9. Useful ROS 2 Commands

| Command | Description |
|---|---|
| `ros2 pkg list` | List installed ROS 2 packages |
| `ros2 node list` | List active nodes |
| `ros2 topic list` | List available topics |
| `ros2 topic echo /topic_name` | Display topic messages |
| `ros2 topic info /topic_name` | Inspect topic information |
| `ros2 service list` | List available services |
| `ros2 action list` | List available actions |
| `colcon build` | Build workspace |
| `colcon build --symlink-install` | Build using symlink installation |

## 10. Clean and Rebuild

If build errors occur, clean generated directories:

```bash
cd ~/RobotSlam

rm -rf build install log

colcon build
```
